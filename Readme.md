### `> whoami`

**Earn from what I know, build from what I earn.**

I don't learn a tool because it's popular — I learn it because I want to know what's underneath it. If I use a library, a model, or an algorithm, I eventually go looking for the math or mechanism behind it. This profile isn't a portfolio; it's a running log of `idea → model → code → experiment → data → analysis → improvement`, versioned in public rather than polished after the fact.
